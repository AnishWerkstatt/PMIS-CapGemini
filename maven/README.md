# Maven practice programs

This project uses the standard Maven directory layout:

- `src/main/java` contains application source code.
- `src/test/java` contains automated tests.
- `target` is generated by Maven and contains compiled output.

Open a terminal in this directory and run:

```text
mvn clean compile
mvn test
mvn package
```

Run one of the examples through Maven:

```text
mvn exec:java -Dexec.mainClass=com.anish.HelloMaven
mvn exec:java -Dexec.mainClass=com.anish.HelloMaven -Dexec.args="Anish"
mvn exec:java -Dexec.mainClass=com.anish.BasicCalculator -Dexec.args="12 5"
mvn exec:java -Dexec.mainClass=com.anish.StudentScores
```

The first command downloads the required Maven plugin if it is not already
available, compiles the Java source, and then starts the selected `main`
method.
